## Installing the Mac apps

One tap, one `brew upgrade` for everything in it, and uninstalls that take their
preferences with them.

```bash
brew tap perfectoweb/tap
brew install --cask belay
```

[**PerfectoWeb//tap**](https://github.com/PerfectoWeb/homebrew-tap) has the casks and what each one promises.
